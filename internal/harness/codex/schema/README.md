# Codex app-server schema (subset)

The JSON Schema for the parts of the `codex app-server` protocol the adapter uses, as generated by codex-cli 0.166.0. The Go types in `../protocol.go` are written by hand from these files. They are a reference, not generated code: regenerate and compare them when the installed version changes.

Generated with:

```
codex app-server generate-json-schema --experimental --out <dir>
```

The full bundle is about 5.8 MB in 467 files. Only these were kept: `v1/Initialize*`; in `v2/`, `thread/start`, `thread/resume`, `thread/read`, `thread/list`, `turn/start`, `turn/steer`, `turn/interrupt`, and the `turn/started`, `turn/completed`, `item/started`, `item/completed`, `item/agentMessage/delta` and `serverRequest/resolved` notifications; at the top level, the command, file-change and permissions approval requests, `item/tool/requestUserInput`, and the `ServerRequest` union, which lists every request the server can send.
