Move Codex to one shared app-server per environment so `codex --remote` can attach a native TUI to a managed thread with approvals broadcast and first answer winning, as X8 and X9 in the capability report demonstrated. The transport is experimental upstream; any attached indicator must not imply an exclusive lock the server does not enforce.
