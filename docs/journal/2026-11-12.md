### What was built

- `cmd/mega/desktop.go`: `desktopLaunch(executable, shell, plain)` builds the `Exec` line. For bash, zsh or fish, named by an absolute `SHELL`, it is `"<shell>" -i -c "exec '<mega>' daemon"`. - `internal/harness`: `Check()` joins the `Harness` interface, with `MissingError{Harness, Executable, Reason}` (`Is(ErrExecutableMissing)`) and `FindExecutable`, which uses `LookPath` for a bare name and stats a path. - The UI: `LaunchDialog` takes `unavailable` and `path`. A harness that cannot run is `disabled`, marked "(cannot run)", with a notice naming the reason and mega's `PATH`. Launch carries the reason, and the initial harness is the first that can run.

- **A scroll the page has not seen yet.** To make the newer-activity control appear, the suite scrolls the history up. A stream delta that lands before the page has the scroll event still counts as following and snaps back. The suite waits two animation frames, by which time the scroll event has been delivered, then prompts.
- **Opening a conversation reads it.** `side.mjs` gives both waiting conversations a pending request, so needs-you keeps two entries however often they are opened. With one, the bare-n step could not tell one step from two.
- **Removing a project with a running conversation.** The removal step removes lowercase `alpha`, which has no conversations; `Alpha` has a running one, so its removal is refused.
