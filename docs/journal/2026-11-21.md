# 2026-11-21

## dfw v0.1.7, and mega on it (implementation agent, for Jens)

Michael merged dfw pull request 1 into v0.1.7, with five commits of his own on top after a terminus review. Mega now requires v0.1.7, and the `replace` that pointed at Jens's dfw checkout is gone.

- **One API change reached mega.** `DaemonApp.OnReopen` is `func(daemonAddr string)` now. Mega passes `func(string) { open() }`, because its `open` already knows the address.
- **Nothing else in v0.1.7 changes what mega does.** The other changes:
  - the window answers the quit Apple Event (Dock, logout, script) by closing;
  - a window with no size gets its close and minimize buttons, which mega never needed, since it sets `InitialSize`;
  - `OnCloseRequest` fails before a window opens, and mega sets none;
  - a tray with no icon still shows its title, and mega's has an icon.
- **Two gaps Michael's review left open, as dfw cards.** Both were checked against mega:
  - **`macos-daemon-quit-apple-event`.** A logout, or `quit app "mega"`, ends mega's daemon inside AppKit's `terminate:`. The gate is not consulted, nothing is released, and the next start sees unsupervised runtimes. That breaks "every way out is the orderly stop" on macOS. `docs/current/mega.md` and the CHANGELOG say so now, and the macOS card lists it. When dfw routes the event, mega must decide whether its gate may decline a logout, since declining cancels the logout.
  - **`macos-javascript-dialogs`.** `alert`, `confirm` and `prompt` do nothing in a macOS window. Mega's page calls none of them, checked with a search of `ui/src`. Should a dialog ever be added, it stays in the page, as every one is now.
- **Duplicate windows on reopen are mega's concern** (dfw's ruling: single-instance enforcement is a non-goal there). Mega opens a new window on every reopen, as Jens chose.

Verified: `cmd/mega` and `internal/config` pass on macOS against v0.1.7 from the module proxy. A `CGO_ENABLED=0` linux/amd64 build and vet pass. `build/mega.app` was rebuilt, and `go version -m` shows dfw v0.1.7 in it.
